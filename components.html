Component Library

Components

Components are reusable interface elements built from the foundations of the design system. They translate tokens for color, typography, spacing, layering, and iconography into practical UI patterns that can be reused across the portfolio website.

Button

Buttons are used for primary actions, navigation, and interactive calls to action. The system supports default, hover, and disabled states. 

<button class="ds-button">Primary button</button>
<button class="ds-button is-disabled" disabled>Disabled</button>

Text input

Text inputs are used in forms and interface controls. The system defines default, focus, and error states. 

<input class="ds-input" type="text" placeholder="Default input" />
<input class="ds-input is-error" type="text" value="Error state" />

Checkbox

Checkboxes allow users to select one or more options. The system supports default, checked, and disabled states. 

<label class="ds-checkbox-row">
  <input type="checkbox" class="ds-checkbox" />
  <span>Unchecked option</span>
</label>

Dropdown

Dropdowns are used for category selection, filtering, and compact option lists in the portfolio interface. 

<select class="ds-select">
  <option selected>Select category</option>
  <option>Film</option>
</select>

Card

Cards are containment components used to group related content. They are used throughout the system for foundations, references, and structured information blocks.

Card

Structured content container

Cards group content into readable blocks with consistent padding, border treatment, and surface hierarchy. 

<article class="ds-card">
  <p class="label">Card</p>
  <h3>Structured content container</h3>
  <p>Cards group content into readable blocks.</p>
</article>

Media card

Media cards are used for project thumbnails and portfolio previews. They combine image ratios, typography, and metadata into a reusable pattern.
