Overview

Design System

This design system is the scaffold for my portfolio website. It adopts structural principles from modern design systems and adapts them to a visual language centered on clarity, atmosphere, and strong hierarchy.

Guiding philosophy

Structure, restraint, and media-first presentation

Structure

The system uses consistent grids, spacing, breakpoints, and layering rules to create predictable layouts across the site. This structure reduces visual noise and makes the interface easier to navigate, document, and expand.

Restraint

The design language is intentionally limited. Typography, color, iconography, and media treatments are controlled so that the work itself remains the focus rather than being overwhelmed by decorative interface choices.

Media-first presentation

My portfolio includes short films, video games, photography, and design documentation. The system therefore supports multiple media formats through flexible aspect ratios, modular layouts, and clear typographic hierarchy.

Systematic consistency

The goal of this design system is not only visual consistency, but also reusability. Foundations and components are documented with code so they can be applied across future portfolio pages and expanded into a larger component library.

Approach

Adopt, then adapt visually

What I adopted

A 12-column grid, an 8-point spacing system, responsive breakpoints, layered hierarchy, and an outline-based icon approach. These structural foundations are based on established design-system conventions so the portfolio can remain scalable, coherent, and easy to extend.

What I adapted

Typography choices, color palette, image treatment, icon usage, and the overall mood of the interface were adapted to reflect my creative practice. The system supports a portfolio centered on film, games, photography, and design work while keeping the interface controlled and readable.

References

Reference systems and inspiration

Design systems studied

This design system was developed through the study of established documentation systems and UI foundations. These references informed the structure of the layout, hierarchy, tokens, and documentation style used throughout this project.

  • IBM Design Language
  • Adobe Spectrum
  • Google Material 3 Foundations
  • GoodBarber UX Foundations
  • Carbon Design System

Why these references matter

IBM and Carbon informed the documentation layout and systematic clarity of the site. GoodBarber was especially useful for defining foundations such as grid, spacing, breakpoints, layering, color, typography, aspect ratios, and icons. Material and Spectrum helped reinforce the importance of role-based systems, consistency, and scalable interface patterns.
