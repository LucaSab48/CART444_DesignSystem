Foundation 01

Grid

This design system uses a 12-column responsive grid as its primary layout structure. The grid aligns elements and organizes space so layouts stay consistent across pages and devices. In this system, margins frame the content, gutters separate columns, and the column structure supports balanced, scalable compositions for both documentation and interface layouts.

Grid structure

Property Value Purpose
Columns 12 Flexible layout system for text, image, and interface elements
Max content width 1100px Keeps content readable on large screens
Gutter 24px Creates consistent separation between columns
Outer margins 24px–48px Maintains breathing room at different viewport sizes

Responsive behavior

On desktop, the grid supports wider multi-column compositions. On tablet and mobile, the layout becomes more compact, with legibility and vertical flow taking priority while spacing and alignment stay consistent.

CSS implementation

.main-content {
  max-width: 1100px;
}

.grid-stage {
  display: grid;
  grid-template-columns: 48px 1fr 48px;
}

.grid-columns {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
}

@media (max-width: 1024px) {
  .grid-stage {
    grid-template-columns: 28px 1fr 28px;
  }
}
