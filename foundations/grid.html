Foundation 01

Grid

The system uses a 12-column responsive grid. This is a flexible structure for organizing text, images, and interface elements across mobile, tablet, and desktop layouts.

12-column layout

Grid specs

Property Value
Columns 12
Max content width 1100px
Gutter 24px
Outer page padding 32px–48px depending on viewport

CSS example

.demo-grid {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 24px;
}
