Foundation 02

Spacing

Spacing defines the distance between elements and helps create a layout that feels readable, balanced, and intentional. This system uses a consistent spacing scale to organize content within components, between groups of content, and across entire page layouts.

Spacing scale

The system uses a modular spacing scale based on small, repeatable values. Smaller increments support detailed interface adjustments, while larger values create separation between sections, cards, and layout groups.

Spacing tokens

Token Value Typical use
space-1 4px Fine adjustments and very small separations
space-2 8px Small internal spacing and compact UI details
space-3 16px Default spacing inside components and between related items
space-4 24px Medium separation between cards or content groups
space-5 32px Section padding and larger layout spacing
space-6 48px Large layout separation
space-7 64px Major section breaks and spacious layouts
space-8 96px Large vertical spacing between major page regions
