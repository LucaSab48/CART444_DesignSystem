Foundation 05

Color

The color system defines the visual tone of the interface and creates a consistent hierarchy across pages, components, and interactions. This palette combines a soft light background, deep cool-toned interface colors, and a warm accent to create a system that feels calm, structured, and visually distinct.

Core palette

These four colors form the base of the system. They are used as background, primary interface color, secondary text color, and accent.

Background

#F5FBE6

Soft page background and low-intensity surface tone.

Primary

#215E61

Primary interface color for emphasis, structure, and surfaces.

Secondary / Text

#233D4D

Main text color and dark supporting surface color.

Accent

#FE7F2D

Accent color for buttons, callouts, and highlighted interactions.

Color roles

Colors are assigned by role rather than only by hue. This makes the palette easier to reuse consistently across the portfolio site and future components.

Role Token Hex Use
Background --color-background #F5FBE6 Overall page background and light layout surfaces
Surface --color-surface #FFFFFF Cards, panels, overlays, and elevated content blocks
Primary --color-primary #215E61 Primary interface emphasis, structure, and larger UI sections
Secondary --color-secondary #233D4D Main text, dark surfaces, and strong contrast areas
Accent --color-accent #FE7F2D Calls to action, active states, highlights, and visual emphasis
Border --color-border #D9E0D0 Subtle boundaries between surfaces and layout regions
Text --color-text #233D4D Default heading and body text
Muted text --color-text-muted #5F6B67 Supporting descriptions, captions, and secondary metadata

Usage combinations

The examples below show how the palette behaves in interface contexts. These combinations define what text can sit on what background and how the accent color should be used.

Default reading surface

Dark text on light background

Body text and headings should primarily sit on the background or white surface colors for maximum readability.

Primary surface

Light text on primary

Primary blocks can be used for emphasized sections, navigation treatments, or strong content groupings.

Secondary surface

Light text on secondary

The secondary color supports high-contrast content and deeper UI states such as dark cards or major structural elements.

Accent interaction

Accent for calls to action

The accent should be used sparingly so it retains visual strength for buttons, links, and key interactive moments.

Do / don’t

Do

Use the accent selectively

Keep orange reserved for important actions and highlights so it remains visually meaningful.

Don’t

Overuse saturated color

Avoid using primary, secondary, and accent at equal intensity in the same layout region. This weakens hierarchy.

:root {
  --color-background: #F5FBE6;
  --color-surface: #FFFFFF;
  --color-primary: #215E61;
  --color-secondary: #233D4D;
  --color-accent: #FE7F2D;
  --color-border: #D9E0D0;
  --color-text: #233D4D;
  --color-text-muted: #5F6B67;
}
