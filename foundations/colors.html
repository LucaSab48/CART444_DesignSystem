Foundation 05

Color

The color system uses role-based tokens rather than isolated colors. This creates consistency across pages, improves contrast control, and makes it easier to reuse the same palette in the future portfolio website.

Palette

Primary / Text

#161616

Background

#F3F3F3

Surface

#E8E8E8

Accent

#0F62FE

Usage

Token Purpose
Primary Main text, headings, and high-contrast interface content.
Background Overall page background.
Surface Cards, panels, boxes, and UI groupings.
Accent Links, focus points, and highlighted interface actions.

CSS tokens

:root {
  --color-bg: #f3f3f3;
  --color-surface: #ffffff;
  --color-surface-2: #e8e8e8;
  --color-text: #161616;
  --color-text-muted: #525252;
  --color-border: #d9d9d9;
  --color-accent: #0f62fe;
}
