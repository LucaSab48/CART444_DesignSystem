Foundation 07

Image Aspect Ratios

Image ratios create consistency and rhythm. Standardized ratios make it easier to build project cards, hero media, galleries, and thumbnails.

Preferred ratios

16:9

Hero images and video previews.

4:3

Editorial images and process documentation.

3:2

Photography and portfolio project stills.

1:1

Thumbnails, icons, and modular gallery items.

CSS example

.aspect-16-9 { aspect-ratio: 16 / 9; }
.aspect-4-3  { aspect-ratio: 4 / 3; }
.aspect-3-2  { aspect-ratio: 3 / 2; }
.aspect-1-1  { aspect-ratio: 1 / 1; }
