Foundation 07

Image Aspect Ratios

Aspect ratio defines the proportional relationship between the width and height of an image or video frame. Consistent ratios help maintain visual rhythm across the interface, support alignment within the grid system, and ensure that media presentation feels structured rather than arbitrary. This design system uses a small set of standard ratios to support the different media types present in my portfolio, including short films, video games, photography, and documentation.

Ratio roles

Each ratio is associated with a specific type of content. Using a limited set of ratios ensures that images align predictably within the grid while maintaining a clear visual hierarchy between different types of media.

Ratio Use Reason
16:9 Short films, trailers, moving image work Standard cinematic and digital video format
4:3 Documentation images and process material Balanced frame suitable for presentation imagery
3:2 Photography Common photographic ratio with natural visual balance
1:1 Game thumbnails and modular gallery previews Compact square format suited for repeated grid layouts
2:1 Wide banners and installation documentation Panoramic composition for horizontal presentation

System logic

Aspect ratios work in conjunction with the grid system to create predictable media layouts. When images share consistent proportions they align more easily within columns and maintain a stable rhythm across pages.

Within this design system, 16:9 supports cinematic video content, 3:2 and 4:3 support photography and documentation, while 1:1 supports thumbnails and modular grid layouts. A wider 2:1 ratio is used selectively for banners and panoramic documentation images.
