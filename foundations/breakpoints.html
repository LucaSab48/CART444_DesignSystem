Foundation 03

Breakpoints

Breakpoints define how the design adapts across devices. They support readability, layout flexibility, and responsive behavior.

Responsive ranges

Size class Width Use
Mobile 0–600px Compact single-column layouts
Tablet 601–1024px Medium-width layouts and adjusted spacing
Desktop 1025px+ Expanded layout with sidebar and larger grids

CSS example

@media (max-width: 1024px) {
  .site-shell {
    grid-template-columns: 1fr;
  }
}
