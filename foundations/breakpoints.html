Foundation 03

Breakpoints

Breakpoints define when the layout should adapt to different screen sizes. They support responsive design by changing the structure, spacing, and proportions of the interface so that content remains readable and usable across mobile, tablet, desktop, and large desktop screens.

Responsive breakpoint ranges

This system uses four main viewport ranges. As the screen grows, the layout can support more columns, wider content areas, and larger spatial relationships. On smaller screens, the system simplifies into more compact, vertically stacked layouts.

Breakpoint behavior

Range Viewport width Grid behavior Typical layout use
Mobile 0–599px 4-column structure Single-column or tightly stacked layouts
Tablet 600–1023px 8-column structure Expanded text layouts and medium-width groupings
Desktop 1024–1439px 12-column structure Main portfolio and documentation layouts
Large Desktop 1440px+ 12-column structure with wider spacing Large screens with more generous negative space

Implementation logic

Below the smallest breakpoint, the smallest layout rules are used. Above the largest breakpoint, the largest layout rules are used. Between breakpoints, the system shifts to the next defined layout range.

CSS implementation

:root {
  --bp-mobile: 600px;
  --bp-tablet: 1024px;
  --bp-desktop: 1440px;
}

@media (min-width: 600px) {
  /* tablet rules */
}

@media (min-width: 1024px) {
  /* desktop rules */

  /* large desktop rules */
