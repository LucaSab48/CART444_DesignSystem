Foundation 06

Typography

Typography shapes hierarchy, rhythm, and readability across the interface. This design system uses a two-font pairing: Khand for titles and display text, and Hind for body text and supporting interface copy. The pairing creates strong contrast between expressive headings and highly readable paragraphs, labels, and documentation text.

Font pairing

The system uses one display family and one reading family. Limiting the palette to two fonts keeps the interface coherent while still creating a clear hierarchy between expressive titles and functional text.

Display / Titles

Khand Bold

Used for display, headline, and title roles.

Body / Interface

Hind Regular

Used for body copy, labels, legal text, and UI descriptions.

Type scale

The type system is organized into role-based styles. Display and headline sizes scale responsively with the viewport, while body and label roles stay tighter and more controlled for consistent reading and interface use.

Display

Khand Bold · clamp(3rem, 6vw, 5.5rem)

Design systems shape experience

Headline

Khand Bold · clamp(2.25rem, 4vw, 3.5rem)

Typography creates structure and emphasis

Title

Khand Bold · 2rem

Titles guide the reader through the page

Body

Hind Regular · 1.05rem / 1.65

Body text is designed for longer reading. It should remain readable, calm, and visually stable across documentation pages, interface copy, and project descriptions.

Label

Hind Regular · 0.875rem / 1.4

Interface label, metadata, small heading

Legal

Hind Regular · 0.75rem / 1.4

Small print, footnotes, low priority system text

Design language for clarity and atmosphere

Khand creates emphasis. Hind carries the reading load.

This pairing supports a visual language that feels structured and cinematic without sacrificing readability. Titles become expressive, while paragraphs and interface text stay stable and easy to scan.

Typography principles

Principle Rule
Font pairing Use only Khand Bold and Hind Regular to maintain consistency.
Hierarchy Use Khand for titles and Hind for reading/interface text.
Readability Keep body text at a comfortable line height and avoid overly long line lengths.
Responsiveness Display and headline roles scale with viewport size; body roles remain more controlled.
Restraint Avoid introducing extra font families or excessive weights.
