Foundation 04

Layers

Layers organize visual hierarchy by placing interface elements on different depth levels. In this design system, layering helps separate background surfaces, content regions, elevated components, and overlays. This creates clearer eye movement, stronger emphasis, and a more flexible interface structure.

Layer hierarchy

The system uses a small set of layer roles. Base layers hold the page background and structural surfaces, content layers hold primary information, elevated layers highlight interactive elements, and overlay layers sit above the rest of the interface when additional focus is needed.

Layer 1

Background

Page background and base structural surfaces.

Layer 2

Content

Main reading area, text blocks, and primary layout regions.

Layer 3

Elevated UI

Cards, controls, and elements that need stronger emphasis.

Layer 4

Overlay

Dialogs, menus, and temporary focused interface states.

Applied layering example

The example below shows how layers work together in an interface. A base canvas supports the page, content blocks sit above it, cards are elevated further, and a modal overlay sits on top to draw the user’s attention.

Overlay

Focused layer

Layer tokens

Token Value Use
layer-base 0 Background canvas and foundational surfaces
layer-content 10 Primary content regions and reading surfaces
layer-elevated 100 Cards, controls, and emphasized interface objects
layer-overlay 1000 Dialogs, popovers, menus, and temporary overlays

CSS implementation

:root {
  --layer-base: 0;
  --layer-content: 10;
  --layer-elevated: 100;
  --layer-overlay: 1000;
}

.modal {
  z-index: var(--layer-overlay);
}

.card {
  z-index: var(--layer-elevated);
}
