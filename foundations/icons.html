Foundation 08

Icons

Iconography provides a compact visual language for actions, navigation, metadata, and interface cues. This design system adopts a simple outline icon style rather than designing a custom icon family from scratch. The goal is clarity, consistency, and efficient reuse across pages, project cards, buttons, and interactive interface elements.

Icon style

The system uses outline icons with a clean geometric structure. Icons are reduced to essential forms so they remain readable at small sizes and do not compete with typography.

Sizing and usage

Icons are sized by role. The default interface icon size is 24px, which keeps actions readable in buttons and navigation. Smaller sizes may be used inline with text, while larger icons are reserved for section level emphasis.

Size Use Rule
16px Inline metadata and compact utility cues Use sparingly and only where visual clarity remains high
24px Default buttons, navigation, and system actions Primary icon size for the interface
32px Section markers or featured icon moments Use for emphasis, not dense interface repetition

Accessibility

Icons that represent actions should include accessible labels when used on their own. Decorative icons should be hidden from assistive technologies. Icons should not be the only carrier of meaning where text can improve clarity. 

<button aria-label="Watch trailer">
  <svg class="system-icon" viewBox="0 0 24 24" aria-hidden="true">
    ...
  </svg>
</button>

CSS implementation

.system-icon {
  width: 24px;
  height: 24px;
  stroke: currentColor;
  stroke-width: 2;
  stroke-linecap: round;
  stroke-linejoin: round;
  fill: none;
}

  width: 16px;
